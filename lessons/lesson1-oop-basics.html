Почему ООП в Python проще, чем кажется

Главная аналогия: Метаданные 1С vs Классы Python

Вместо абстрактных примеров с «животными» из учебников, мы используем архитектурный подход 1С. Когда вы создаете справочник в Конфигураторе, вы по сути описываете чертеж сущности. В Python класс выполняет ровно ту же роль.

В 1С:Предприятии В Python
Объект метаданных Класс (class)
Реквизит (Код, ИНН) Атрибут экземпляра
Модуль объекта (Процедуры) Методы класса (def)

Пример: Защита данных (Инкапсуляция)

В 1С логику проверки данных мы пишем в обработчике ПередЗаписью(). В Python мы инкапсулируем логику внутрь методов класса, чтобы никто не мог изменить важные свойства напрямую:

class Wallet:
    def __init__(self):
        self.__balance = 0  # Скрытое свойство (приватный атрибут)

    def deposit(self, amount):
        if amount > 0:
            self.__balance += amount
        else:
            print("Сумма должна быть положительной!")
