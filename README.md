## 🎯 Цель проекта
Разрушить главный барьер в понимании объектно-ориентированного программирования (ООП). Вместо абстрактных и бесполезных «кошек» и «машинок» из учебников, я перевожу концепции Python на понятный технический язык 1С (Справочники, Документы, Реквизиты, Таблицы значений).

## 🗺️ Карта параллелей, которую я собираю

| Концепция в Python 🐍 | Аналог в 1С:Предприятии 🛠️ | Для чего нужно? |
| :--- | :--- | :--- |
| **Класс (`class`)** | **Объект метаданных** (например, СправочникКонтрагенты) | Чертеж будущей сущности |
| **Объект / Экземпляр** | **Ссылка / СправочникОбъект** (конкретный элемент) | Реальные данные в памяти |
| **Метод (`def`)** | **Процедура / Функция** в модуле объекта | Поведение и логика объекта |
| **Атрибут / Свойство** | **Реквизит** (Код, Наименование, ИНН) | Данные, скрытые внутри объекта |
| **Список (`list`)** | **Массив** | Простой перечень элементов |
| **Матрица / Список списков**| **Таблица значений** | Табличные данные |
